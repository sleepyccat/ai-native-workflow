# cr-general 学习记录

## 用户偏好

- **git diff 基准**：必须使用 `merge-base` 确定分支起点，绝不能直接用 `master..<feature>` 对比。原因：master 上可能有其他 MR 合入的代码，会产生反向 diff，混入不属于当前分支的文件变更。
- **MR 触发方式**：用户会直接说 `CR MR xxxxx` 或 `CR 分支名`，AI 应自动通过 git 获取变更范围，无需询问文件列表。
- **输出方式**：默认直接输出到对话，不需要每次询问。
