# development-design

设计文档生成。

## 触发词

- "设计文档" / "写设计" / "生成设计"
- "开发设计" / "技术设计"

## 功能

1. 独立生成：给需求描述或 PRD，AI 分析代码后生成设计文档
2. 被 daily-workflow 第二步自动引用

## 文档结构

1. 文档元信息（PRD 链接、开发人、接口文档等）
2. 功能总结（核心功能点 + 非功能性要求）
3. 交互流程图
4. 组件间数据流动图
5. 修改文件表格
6. 风险与依赖
7. 自测计划概要

技术栈特定的模板内容（元信息字段、文件路径示例、数据流动图示例等）详见 `references/design-template.md`，可按团队替换。

## 个性化配置

`references/` 目录存放用户可编辑的引导配置，换团队/换技术栈时替换即可：

- `design-template.md` — 技术栈专项模板配置

## 飞书集成（可选）

本 skill 支持三种输出方式：
1. **对话输出**（默认）：直接在对话中展示
2. **飞书文档**：需安装 `feishu-doc` skill 并配置凭证
3. **本地 MD 文件**：自动保存到 `{SKILLS_DIR}/development-design/output/{项目名}/`

## 自我学习

本 skill 具备独立的学习和反馈机制，详见 `LEARNING.md`。

- 每次用户对 AI 输出做修改/驳回/补充时自动记录反馈
- 同类修改 ≥2 次建议更新规范，驳回 ≥1 次下次规避，确认 ≥3 次固化最佳实践
- 所有学习记录和沉淀的规范更新都在 `LEARNING.md` 中可追溯
