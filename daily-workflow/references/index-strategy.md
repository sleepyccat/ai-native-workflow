# 结构化索引（长期记忆层）

为解决跨会话记忆丢失和文档积累后检索效率低的问题，维护一个全局索引文档作为结构化记忆入口。

- **飞书后端**：`AI-docs/index` 飞书文档
- **本地后端**：`{SKILLS_DIR}/daily-workflow/output/{项目名}/dw-index.md`

## 索引文档格式

索引文档内容结构如下（飞书版采用飞书文档，本地版采用 Markdown 文件，格式一致）：

### 需求索引（按季度分组，组内按时间倒序）

```
## 2026 Q2
| 日期 | 需求名 | 状态 | 分支名 | 关键技术点 | 文档链接 |
|------|--------|------|--------|------------|----------|
| 04/28 | 列表页重构 | 已上线 | feature/list-refactor | Antd Table 虚拟滚动 + 接口分页 | [需求分析](链接) |
| 04/15 | 配置管理 | 开发中 | [PM](链接) | feature/config-mgr | 动态表单 + 拖拽排序 | [需求分析](链接) |

## 2026 Q1
| 日期 | 需求名 | 状态 | 分支名 | 关键技术点 | 文档链接 |
...
```

### 零散工作索引（按月分组）

```
## 零散工作 - 2026/04
| 日期 | 工作内容 | 状态 |
|------|----------|------|
| 04/30 | 修复列表展示bug | 已完成 |
| 04/25 | 技术方案评审会 | 已完成 |
```

### 技术标签索引（底部维护）

```
## 技术标签索引
- 列表页：列表页重构(04/28)、列表展示bug(04/30)
- 性能优化：列表页重构(04/28)
- 配置管理：配置管理(04/15)
```

## 需求摘要区

每个需求的管理文件头部维护结构化摘要：

```
> **摘要**
> - 一句话描述：xxx
> - 核心技术方案：xxx
> - 涉及模块/页面：xxx
> - 最终状态：xxx
> - 完成日期：xxx
```

## 索引维护时机

| 时机 | 操作 |
|------|------|
| 第一步需求分析完成 | 插入新条目（状态"分析中"）；创建摘要区 |
| 第二步设计文档完成 | 更新摘要区"核心技术方案"；更新条目"关键技术点" |
| 第七步提测完成 | 更新条目状态；更新摘要区最终状态 |
| 状态变更（已上线等） | 更新条目状态；更新摘要区最终状态和完成日期 |
| 快速记录 | 追加零散工作索引条目 |
| 技术标签变化 | 更新技术标签索引 |

## 检索路径

| 场景 | 检索路径 |
|------|----------|
| 写周报 | 读 `dw-state.json` 各需求的 `daily_log` + `daily-log.md` 本周记录 |
| 写季度总结 | 读 `index` 对应季度 → 按需读摘要区 → 极少数读完整文档 |
| 写年度总结 | 读 `index` 全部季度 + 技术标签 → 按需读摘要区 |
| 继续 dw | 读 `index` 找到条目 → 跳转管理文件 |
| 了解某个需求 | 读 `index` → 读摘要区 → 按需读完整文档 |

## 本地模式（storage_backend = local）

当未配置飞书 MCP 时，使用本地文件替代：

### 索引文件

- 维护 `dw-index.md` 作为结构化记忆入口，格式与飞书版一致
- 每个需求在 `dw-state.json` 中维护结构化信息，`dw-index.md` 作为快速检索入口

### 需求摘要区

每个需求文档（`dw-docs/[需求名]_需求分析.md`）头部维护摘要区，格式与飞书版一致。

### 索引维护时机

与飞书版时机相同，操作改为更新 `dw-index.md` 和 `dw-state.json`：

| 时机 | 操作 |
|------|------|
| 第一步需求分析完成 | 在 `dw-index.md` 需求索引中插入新条目；在需求分析文档头部创建摘要区 |
| 第二步设计文档完成 | 更新摘要区"核心技术方案"；更新 `dw-index.md` 条目"关键技术点" |
| 第七步提测完成 | 更新 `dw-index.md` 条目状态；更新摘要区最终状态 |
| 状态变更 | 更新 `dw-index.md` 条目状态；更新摘要区最终状态和完成日期 |
| 快速记录 | 在 `dw-index.md` 零散工作索引追加条目 |
| 技术标签变化 | 更新 `dw-index.md` 技术标签索引 |

### 检索路径

| 场景 | 检索路径 |
|------|----------|
| 写周报 | 读 `dw-state.json` 各需求的 `daily_log` |
| 写季度总结 | 读 `dw-index.md` 对应季度 → 按需读摘要区 → 极少数读完整文档 |
| 写年度总结 | 读 `dw-index.md` 全部季度 + 技术标签 → 按需读摘要区 |
| 继续 dw | 读 `dw-index.md` 找到条目 → 跳转对应文档 |
| 了解某个需求 | 读 `dw-index.md` → 读摘要区 → 按需读完整文档 |
