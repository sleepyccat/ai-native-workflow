# 前端需求分析关注点

> 本文件为用户可编辑的参考配置，requirement-analysis 执行代码对照分析时读取。
> 列出前端场景下需求分析时必须关注但 PRD 容易遗漏的点。换团队时替换此文件即可。

## 用户交互

- [ ] 操作反馈：用户点击提交/保存后，是否有明确的成功/失败反馈
- [ ] 防重复提交：连续点击是否会导致重复请求，是否有 loading/disabled 保护
- [ ] 未保存离开：表单编辑中途关闭页面或切换路由，是否有未保存提示
- [ ] 键盘操作：Enter 是否触发提交，Esc 是否关闭弹窗，Tab 顺序是否合理
- [ ] 撤销/重做：复杂操作是否支持撤销，数据变更后能否回退

## 刷新与缓存

- [ ] 页面刷新：F5 刷新后表单数据是否丢失，当前步骤/状态是否保持
- [ ] 接口缓存：列表页进入详情再返回，是否需要重新请求还是使用缓存数据
- [ ] 浏览器后退：点浏览器后退按钮，页面状态是否正确（不是白屏或 404）
- [ ] bfcache：前进后退时页面是否从缓存恢复，定时器/事件监听是否正确处理
- [ ] 强制刷新：Ctrl+Shift+R 后静态资源是否正确更新，接口数据是否重新拉取

## 多标签页与并发

- [ ] 多标签页：同一用户在多个标签页操作相同数据，是否会导致数据冲突
- [ ] 权限变更：管理员修改了用户权限，用户已打开的页面是否需要实时更新
- [ ] 数据过期：用户长时间停留在页面后操作，数据是否已过期，是否需要重新拉取

## 加载与异常

- [ ] 首屏加载：页面首次打开是否有骨架屏/loading，白屏时间是否可接受
- [ ] 接口超时：接口响应慢时是否有超时提示，是否支持重试
- [ ] 网络断开：弱网或断网时操作是否有友好提示，数据是否会丢失
- [ ] 接口降级：非核心接口失败时，页面是否可用（如推荐列表失败不影响主流程）

## 路由与导航

- [ ] 路由参数：URL 参数变更时页面是否正确响应（如直接修改 URL 中的 id）
- [ ] 深链接：用户通过书签或分享链接直接访问某个页面，是否正常工作
- [ ] 404 处理：访问不存在的路由是否有友好提示，是否有返回入口
- [ ] 权限路由：无权限页面直接访问 URL 时，是否正确拦截并提示
